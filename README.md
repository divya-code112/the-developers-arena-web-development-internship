# Personal Portfolio Website

A modern and responsive personal portfolio website built using **HTML5 and CSS3** as part of **The Developers Arena – Week 2: CSS - Styling Your Website** internship assignment.

The project builds upon the HTML portfolio created in Week 1 and focuses on creating an attractive, responsive, and user-friendly interface using CSS.

---

## 📌 Project Overview

This portfolio showcases my:

- Academic background
- Career goal
- Technical skills
- Contact information

The website demonstrates practical implementation of CSS concepts including **selectors, the Box Model, Flexbox, CSS Grid, responsive design, media queries, transitions, hover effects, animations, typography, and custom styling**.
